# Stage A concept art provenance

These four PNGs were generated for the M10 visual review with OpenAI image generation on 2026-10-24. Each prompt described original sci-fi scenes for ArcadeShooter's cooperative research-facility setting: a containment hangar for the menu, four original operators in a deployment bay for the lobby, a first-person facility firefight for the HUD, and an extraction vista for results. The user's collage of existing games was used only to judge visual quality and the amount of space given to environment, characters, and overlays. No reference screenshot was supplied to the image generator.

| File | Concept role |
| --- | --- |
| `facility-menu.png` | Full-bleed facility interior with a containment gate and dark space for navigation. |
| `squad-lobby.png` | Four distinct original armored operators in a deployment bay. |
| `facility-combat.png` | First-person combat composition with central enemy sightline and room for edge HUD. |
| `extraction-results.png` | Facility exterior and ships at dawn as a results backdrop. |

The images are review-only illustrations. They are not imported into Unity, not approved production art, and not representations of the current playable map, character models, or gameplay graphics. The UI overlay mockups use [render-concepts.swift](../render-concepts.swift) to combine these PNGs with locally drawn vector/text elements.
